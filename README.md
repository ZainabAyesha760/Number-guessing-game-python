## Number Guessing Game

A simple Number Guessing Game built with Python.

## How It Works

- The computer randomly selects a number between 1 and 100.
- The player gets 3 attempts to guess the number.
- The program tells the player if the guess is too high or too low.
- If the player guesses correctly, they win.
- If all attempts are used, the correct number is revealed.

- if / elif / else
- while loop
